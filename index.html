よみあげ

電子書籍アプリのページのスクリーンショットを、写真・ファイルアプリ（iCloud Drive・Googleドライブ・このiPhone内）・zip から何回かに分けて追加できます。ファイル名の番号順に並べ（撮影日時順・手で並べ替えも可）、同じページの重複・警告の画面・真っ黒な画面を除いて「03.GrPDF.書籍名.pdf」の本にし、本文だけを読み上げます（PDFとして保存も）。

電子書籍アプリのページを自動でめくりながら「画面収録」した動画を選ぶと、ページごとに取り出して読み上げます（サーバーへ送って処理。動画は処理後すぐ消し、ページ画像も24時間で消えます）。PDF（「03.GrPDF.書籍名.pdf」）として保存もできます。自動ページめくりのやり方

電子書籍アプリ（Kindle など）で読んでいるページのスクリーンショットを、写真から何枚でもまとめて選べます。ファイル名の番号順に並べ、時刻・電池などの表示や「位置No.」などを除いて本文だけを読み上げます。
ショートカットでスクショをまとめたPDF（「03.GrPDF.書籍名.pdf」）は「ファイルを開く」から開くと、自動でスマホ画面として読み、本棚に書籍名・巻の順で並びます。本棚の「✏️」または読んでいる画面の「✏️ 名前を変更」で、一時的な名前のファイルにも書籍名・巻を付けられます。警告表示などが写る時は、読んでいる画面の「✂️ 切り取り」で調整できます。

PDF・画像（スクリーンショット）・テキスト（.txt）・ePub を開いて読み上げます。
画像は複数枚まとめて選べます（選んだ順に読みます）。
文字の入ったPDF・テキスト・ePubは、この端末の中だけで処理します。
スキャンした本などの画像の文字読み取り（OCR）は、設定が「高精度（サーバー）」のとき、ページの画像をこのアプリの配信元サーバーへ送って読み取ります（保存はしません）。

    設定

    使い方：読み間違い・スキャン間違いの直し方

    読み方がおかしい時（文字は正しいのに、読み方が違う）

    1. 本文の、読み方がおかしい言葉を長押しして選びます（青い選択の端を動かして範囲を調整できます）。
    2. 画面の下に出る「〇〇の読み方を登録」をタップします。
    3. 「読み方辞書」が開くので、「読み」にひらがなで正しい読みを入れて「追加する」をタップします。

    画面の文字はそのままで、読み上げだけが変わります。すべてのファイルに効きます。

    文字そのものが違う時（スキャン・OCRの読み取り間違い。例：「猪」が「猫」になっている）

    1. 間違っている文字を長押しして選び、画面の下の「✏️ この行の文字を修正」をタップします。
      （長押しがうまくいかない時は、間違いのある文をタップして読み上げ位置を合わせてから、ページ番号の右の「✏️修正」をタップしても同じ画面が開きます。）
    2. 「文字の修正」の画面に、その行の元の画像（サーバーOCRの時）と文字が出ます。見比べながら文字を直して「保存」をタップします。
    3. 直した文字は、画面の表示と読み上げの両方に使われます（読み方辞書はそのあとに効きます）。ファイルを開き直しても残ります。
    4. 同じ間違いが本のあちこちにある時は、「この修正を本全体に適用（一括置換）」を開き、「件数を確認（プレビュー）」で何か所変わるかを確かめてから「本全体に適用する」をタップします。
    5. 同じ間違いがほかの本にもある時は、「適用する範囲」で「すべての本」を選びます。「件数を確認（プレビュー）」で合計と本ごとの件数を確かめてから「すべての本に適用する」をタップすると、本棚のすべての本に効きます（これから入れる本・読み取る本にも効きます）。
    6. 元に戻す時は、その行の「文字の修正」を開いて「元に戻す」、一括置換は一覧（「この本の一括置換」・「すべての本の一括置換」）の「元に戻す」をタップします。「すべての本の一括置換」の一覧は、設定の「すべての本の一括置換（文字の修正）」からも開けます。

    「◀ 前の行」「次の行 ▶」で、続けて何行でも直せます（直した内容は移動の時に自動で保存されます）。

    直す順番：行ごとの修正 → この本の一括置換 → すべての本の一括置換 → 読み方辞書（読み上げだけ）。

    サーバーURL（音声・OCR用）

    GitHub Pages版（https://vezzita001-ux.github.io/yomiage/）で使う時は、サーバーのURL（https://〜.trycloudflare.com）をここに貼り付けて「保存して接続確認」を押してください。サーバーを起動し直してURLが変わった時も、ここだけ変えれば本棚はそのまま使えます。空欄にすると、今アプリを開いているURLと同じサーバーを使います。

    読み上げエンジン

    抑揚・音量・間（VOICEVOX・AivisSpeech）

    端末の声（iPhoneの声）で変えられるのは「速さ」と「声の高さ」だけです（ブラウザの仕組みの制限）。抑揚・音量・句読点の間は、読み上げエンジンで「VOICEVOX」か「AivisSpeech」を選ぶと調整できます。

    AivisSpeechでは「抑揚」は感情表現の強さとして働きます。声の高さを大きく変えると音質が落ちることがあります。

    画面の色
    文字の読み取り（OCR：画像・スキャンPDF）
    高精度：ページの画像を配信元サーバーに送り、国立国会図書館のNDLOCR-Liteで読み取ります（縦書きの本に強い）。つながらない時は自動で端末内に切り替えます。
    見開き分割（1枚に2ページ分が並んだPDF・画像）
    「する」「自動（横長で中央に余白がある時）」では、右ページ→左ページの順に読みます。ページ上の柱（書名・章題）とページ番号は読みません。
    端末内OCRの書字方向
    文字が無い（ほとんど無い）画像のページで、絵を大きく見せてから次のページへ進みます。「🖼 挿絵」の知らせか画像をタップ（または ⏭）すると、すぐ次へ。
    iPhoneのショートカットで読み上げる（スクショ読み上げ）

    Kindle などを読みながら、iPhoneの背面を2回たたくだけで今の画面を読み上げる「ショートカット」を作れます。下のボタンで、今の声の設定と読み方辞書が入ったURLを作り、ショートカットの「URL」に貼り付けてください（作り方は別にお渡しする手順書を見てください）。

    送ったスクリーンショットはサーバーのメモリに30分だけ置き（表示用）、ディスクには保存しません。読み方辞書はショートカットで使うためサーバーに保存されます（辞書を変えたら、もう一度ボタンを押すと上書きされます。URLは同じままです）。

    音声の診断（この端末の声をすべて表示）
    診断ログ（うまく動かない時に）

    うまく動かない時は、このログをコピーして送ってください（または画面を撮影）。
